# Yoru Akihito Portfolio

A responsive, static anime-artist portfolio website for **Yoru Akihito / Yoru / 夜**.

## Customize
- Replace `assets/hero.png` with your preferred hero artwork if desired.
- Add your real artwork to `assets/art/` and update the gallery cards in `index.html`.
- Replace `your-email@example.com` and the social `#` links with your real links.
- Edit text in `index.html` and colors in `styles.css`.

## Run locally
Double-click `index.html`, or use VS Code Live Server for the best experience.

## Publish with GitHub Pages
Create a repository, upload these files, then enable GitHub Pages from the repository's Settings > Pages. GitHub Pages can publish static HTML/CSS/JS sites. See the official docs: https://docs.github.com/en/pages
